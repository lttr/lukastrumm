So far I've used AI agents mostly interactively. Recently, though, I found a useful job for them: filtering the content I want to follow.

With a Claude Managed Agent I built my own news feed that pulls together blogs and social media posts every day. The upside is that I can read it on an e-ink tablet, without being interrupted by ads or irrelevant posts.

The second example is keeping track of software changes. For Claude Code, I occasionally run a skill that reads my configuration and works out which of all the new features are relevant to me. The skill is here: https://github.com/lttr/claude-marketplace/blob/master/plugins/cc/skills/changelog/SKILL.md
